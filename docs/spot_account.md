# 股票与ETF账户及权益

理解股票和 ETF 的资金、持仓与分红。

## 开始前

- 输入：冻结的现货规则、行情和公司行动。
- 输出：真实账户、权益及估值记录。
- 命令中的尖括号内容是待替换参数。

## 使用顺序

1. 声明期初现金与资产类型。
2. 准入历史规则和公司行动。
3. 执行策略。
4. 对照订单、账户和权益事件。
5. 按实际估值时间解释收益。

当前股票和ETF策略通过本地LEAN执行。账户、订单、成交和公司行动使用ResearchPackage冻结的输入，正式报告与分析直接读取Result。策略声明、安装与准入见[LEAN执行](lean-execution.md)，回调接口见[策略事件协议](strategy-protocol.md)。

## 账户状态

策略读取只读账户，包含持仓、可卖数量、活动订单、可用现金和公司行动权益。金额买单的未消费预占从可用现金中扣除，其他订单不能重复使用。成交仍须满足可用资金、数量格点、T+1、停牌、价格限制和费用要求。

账户使用CNY，现金以分记账。股票价格精度为2，ETF为3。价格整数与现金整数采用各自单位，不能将ETF报价整数直接解释为人民币分。

日线策略按下一交易日开盘执行。一分钟策略按后续完成分钟Close加声明滑点执行。成交及账户状态以引擎实际事件为准，目标或交易意图不能代替已成交持仓。

## 分红与送转

公司行动分别保存公告可见时间、登记日、除权日、现金到账日、股份到账日和可卖日。现金红利按登记持仓确认，在付款前属于应收权益，付款后进入现金。整数送转股份在到账前计入待到账权益，到账后进入持仓，在可卖日前保持锁定。登记后卖出原股不会撤销已经登记的权益。

股票 `finance.STK_XR_XD` 使用供应商当前保存的历史事件，实施公告后首个真实交易日09:15可见。`addTime/modTime`仅为维护信息。请求包含`note`，明确不向原股东分配的转增不产生原持仓权益。

非零权益仍须真实到账和可卖日期。ETF按其版本可见性合同选择实际消费时点可见的行动。

## 估值与收益

日线按最新已可见价格估值：当日Open可用时使用Open，缺Open时使用已知历史价格。账户保存`equity_semantics`、`valuation_at`与逐证券`valuation_marks`，该序列不表示当日收盘净值。一分钟使用已完成行情日终估值。应收红利、待到账股份和锁定股份使用当时可见价格计入权益。

收益包含首日相对期初资金的变化。回撤使用包含期初资金的运行峰值。成交费用已计入账户权益，报告不能重复扣除。金融指标的定义、单位和样本范围随正式Result保存。

## 正式结果与恢复

Result保存`lean/orders`、`lean/intents`、`lean/daily`、`lean/trace`与`lean/metrics`，以及账户终态、策略状态、运行锁、策略输入和引擎摘要。行情、规则、公司行动及信号使用持久工件和计划引用。归档时同时保留这些依赖。

成功节点依据原输入、实现和配置复用checkpoint。未完成LEAN节点整体重跑，不从中间账户状态接续。已发布Result保持只读。

## 已知限制

当前公司行动支持毛额现金分红和整数送转。个人红利税、非整数股份分配及其他行动类型需要独立合同。本页覆盖人民币股票和 ETF 日线与一分钟。

当前现货策略不提供信用账户或融券。期货使用[独立账户合同](lean-futures.md)。


## 常用名称

| 名称 | 含义 |
| --- | --- |
| ResearchPackage | 数据、算法、样本、指标和预算的完整声明 |
| Catalog Lock | 已确认的字段、来源和可见性说明 |
| PIT（按时点可见） | 过去某时刻只使用当时已知的信息 |
| bar（周期行情） | 一个日线或分钟区间的行情记录 |
| OHLCV（开高低收量） | 开盘价、最高价、最低价、收盘价和成交量 |
| Feature（特征） | 决策时已知的研究输入 |
| Label（标签） | 用于评价预测的未来目标 |
| bundle（封存包） | 完整代码、依赖或数据声明及其内容身份 |
| checkpoint（检查点） | 通过验收的节点输出和恢复依据 |
| Result（正式结果包） | 正式表、运行摘要及配置、实现和输入引用 |
| minute_scope（分钟范围引用） | 指向同一冻结日历和历史规则的小引用 |
| Supervisor | 监督运行和提交结果的主进程 |
| Worker | 执行节点计算的独立进程 |
