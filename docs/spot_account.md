# 现货账户与股东权益

本页保留现货账户、公司行动和信用语义，供历史 Result 解读以及当前 LEAN 股票/ETF 执行的账户边界使用。当前生产策略统一由本地 LEAN 执行，日线和分钟策略都必须声明 `execution_backend=lean`；本页的字段和规则说明不是旧 `finance.simulation.daily-cash` CLI 的参数说明。

当前入口、声明和输出见[LEAN 执行](lean-execution.md)与[金融执行、账户与正式结果](financial_simulation.md)。正式报告和分析直接消费 Result。

## 普通现货账户

账户状态至少包括期初现金、持仓、可卖数量、冻结数量、活动订单、应收权益和估值。账户本位币为 CNY；股票按两位价格精度记账，ETF 按三位价格精度记账。交易金额、费用、公司行动和估值必须沿用对应的 `price_scale`，不能把 ETF 金额按股票单位解释。

LEAN 日线按下一交易日开盘执行，分钟按后续完成分钟 Close 加声明滑点执行。现金、持仓、可卖数量、订单预占和日终权益由引擎推进。股票和 ETF 的交易单位、T+0/T+1、停牌、涨跌停、公司行动和费用均来自已准入且按时可见的规则来源。

公司行动按实际登记持仓处理：现金红利经过应收和到账事件进入现金；送股、转增、拆分和合并分别记录股份变化及可卖时点；退市现金清算使用有来源的非交易事件。可卖之前的股份仍保留在未结算或锁定状态。不能用未来公告、未来修订或窗口外收盘价补齐账户状态。

## 账户输入和结果

当前研究包声明账户事实，并由准入和 LEAN 输入工件冻结。历史账户字段可能包括：

| 概念 | 语义 |
| --- | --- |
| `initial_cash_cny` | 研究开始时可用的 CNY 现金 |
| `opening_nav_cny` | 研究开始时的净资产，包含声明的期初持仓和权益 |
| `external_cashflows` | 按可见生效时间切分收益的入金或出金事实 |
| `conversion_plans` | 有来源的证券转换、成本分配、权益承接和可卖安排 |

这些名称描述账户事实，不表示存在同名 CLI 参数。Result 保存实际使用的账户、公司行动和规则引用；恢复继续原计划和 checkpoint，不重新应用资金流或覆盖历史结果。

账户收益以声明的期初净资产为基准。资金流发生时按生效时点切分收益；出金受可用现金、订单预占和负债约束。回撤、收益、费用和税款按正式 Result 的指标及金融表解释，账户扣收不会再次减少已经确认的净资产。

## 信用账户语义

信用账户的历史语义包括本金、利息、融资关联、保证金、维持比例、风险命令和偿还事件。融资利息与成交费用、TCA 分开记录；净资产按现金、持仓、待登记权益和其他负债，再扣除信用本金及未付利息计算。

信用资格、担保品折算、利率、协议期限、风险警示、ST、退市整理状态和成分事实必须按使用时点取得。没有历史可见来源时，不能用当前快照补齐。融资关联持仓发生公司行动时，必须有明确的权益和债务承接合同。

本页不开放分钟信用账户、融券、期货期初账户或旧日频现金仿真入口。底层金融类型仍可被历史 Result 和 LEAN 边界引用；类型或历史字段存在不表示当前可以通过旧命令运行。

## 非交易会话和转换

历史 Result 可能包含没有行情和交易指令的非交易会话，用来推进已声明的退市清算、应收到账或证券转换。此类事实必须带有可见时间、账户来源和规则身份，不能伪造 OHLC、末价或收购价。

转换先注销旧证券，再按来源计划登记后继证券或现金对价；登记前的权益、登记后的未结算股份、可卖时点和成本承接分别保存。实际付款、公告可见和研究现金可用时间不能混为一个日期。
