# 现货账户：现金、持仓与股东权益

买卖股票只是账户变化的一部分。分红、送转、红利税、换股、入出金和融资也会改变现金或持仓。这里说明日频现货路径如何保存这些事实，并由独立检查重建账户。

应收款不等于可用现金；到账日期要有明确来源，不能一律假定下一交易日可用。不同频率与账户模式的支持范围见下文。

## 参数与行为说明

日频 `finance.simulation.daily-cash@1.0.0` 使用公共 Engine、现货 Ledger 和独立金融验证。`account` 是可选 JSON 参数；不声明时保留现金起点。声明后，期初现金、批次、税权和权益事件共同进入执行身份及 Result，旧节点不能跨身份恢复。

## 输入

`account` 必须包含下列字段。没有对应事实时显式提供空列表，不从后续行情补推。

| 字段 | 内容 |
| --- | --- |
| `opening_snapshot` | `SpotOpeningSnapshot.to_dict()`：账户起点、可见截止时间、投资者税务身份、现金及限制、取得批次、应收应付、历史分红权利、已核定税款和待上市权益 |
| `opening_marks` | `SpotOpeningMark` 列表：起点持仓逐证券的已可见市场估值及来源 |
| `tax_rules` | `DividendTaxRule` 列表：身份、证券类别、取得方式、适用日期、自然月／年边界、税率及舍入规则 |
| `dividend_plans` | `DividendRegistrationPlan` 列表：登记、除权、到账时点，每股现金与应税金额、规则及来源 |
| `conversion_plans` | `SecurityConversionPlan` 列表：旧证券注销、新证券登记及可交易时间、比例、现金对价、成本分配、取得日和税权承接、零碎股及转换期间估值 |
| `tax_instructions` | 显式核定／扣收事件：稳定业务键、实际生效时间、来源，核定引用转让，扣收分配到核定 |

可选 `corporate_action_lot_rules` 按 action_id 声明送转／拆并股取得日、可卖时间及税权承接；可选 `settlement_calendar` 为 `{sessions: [交易日字符串], source: AccountSource载荷}`。期末 T+1 买入必须有下一交易日来源，不能用自然日加一天代替。

完整数据类型位于 `domain/spot_account.py`；所有时点必须带时区，金额以人民币分计。`initial_cash_cny` 与期初现金桶及应收合计一致；可以为零，但起点净资产须为正。初始账户无活动订单，受限现金必须有明确限制原因。

## 执行与收益

Ledger 唯一保存现金、持仓桶、应收和应付。`SpotAccountBook` 保存取得批次、分红权利、转让匹配、税款核定与扣收以及证券承接事实，不保存另一套现金余额。平均会计成本与税务取得批次分开；取得日不能被平均成本重置。

初始化不生成市场成交。起点净资产按当时可见市场价值及应收应付计算，不能使用历史成本。总收益与最大回撤均包含声明起点。恢复沿 Runtime 节点提交边界进行，初始化不能重复应用。

分红按登记时批次固定权利，除权确认应收，到账转入现金。登记后卖出不消灭已登记权利。同一证券的现金分红须统一使用账户权益计划，不能同时由普通公司行动重复记入。

`account.dividend_withholding_rules` 可按 `dividend_id` 提供 `DividendWithholdingRule.to_dict()`，显式声明派息预扣税率、舍入与当时可见来源。预扣按本次登记应税总额计算，逐批以累计差额分配，避免逐批舍入多扣；除权应收和到账现金均为毛股息减预扣，税权保留 `prewithheld_units`，后续转让只抵扣对应的剩余已扣金额。送股应税价值由登记计划的 `taxable_per_share_*` 明确提供，不能用现金股息代替。未声明预扣规则时不产生预扣。预扣超过本次毛现金或来源在登记后才可见时拒绝执行。

例如100股、每股现金0.17元、含送股的每股应税基数0.77元，声明5%预扣时毛股息17元、预扣3.85元、净到账13.15元。金额进入账户金融事实，独立账户验证器按封存计划重新计算预扣、净应收和后续抵扣。


卖出按适用规则匹配 FIFO 税务批次，持有期按自然月／年计算。核定确认税费与应付，扣收减少现金和应付，不再次减少净资产。一笔转让可以涉及多个分红，一笔扣收可以分配给多个核定；分次扣收不能超过剩余应付。精确税务模式缺取得信息、遗漏已转让权利核定或终态到期未付义务时拒绝完整结果。

核定指令包含 `kind=assess`、`event_id`、`transfer_id`、`effective_time`、`due_at`、`source`；扣收指令包含 `kind=collect`、`event_id`、`effective_time`、`source`、`allocations`，每项分配为 `assessment_id` 和 `cash_units`。普通卖出转让键采用正式 fill_id，退市转让键为 `delisting:{action_id}`。

换股先注销旧证券，登记前保存独立权益并使用已可见的转换期间估值；登记后形成未结算股份，按每批继承的可卖限制解禁。旧证券目标不能继续增仓，目标不会自动按比例转给新证券。现金对价经应收和到账事件处理，全程不伪造市场 fill。

## 结果与独立复核

`research-daily-cash-financial-context-v1` 保存规则、行情、公司行动、登记事实及 `account_context`。账户事实包含输入、批次账、逐事件记录与会话负债／后继权益快照。规范六表继续保持字段合同；账户估值使用 `cash_plus_positions_and_account_rights_v1`，即现金加持仓、加待登记权益、减已确认应付。

`account_valuation_adjustments` 在仿真 manifest 中绑定会话调整值。独立账户 oracle 从期初明细、成交、税权及换股计划重新计算，再核对调整值和六表；不会调用生产税务或账本算法。金融结果必须与自包含 Result 一起验证，不能仅靠输入哈希或终态余额验收。

## 账户组合报告

组合 HTML 沿用 `qlib-portfolio-report-v1` 请求和正式七表；存在账户上下文时，额外从同一仿真工件的 Result 支持文件 `simulation/daily-context.json` 读取账户事实。报告通过 ResultStore 已验证快照按需加载，不访问运行目录或数据库；`export-result` 副本可独立生成报告，HTML 内嵌图表资源。

账户净值以会话快照封存的 `opening_nav_units` 为分母，不能用期初现金或取得成本替代。回撤的最高值包含期初净资产，因此首个收盘低于起点时显示回撤，与正式账户总收益及最大回撤指标一致。零期初现金但期初净资产为正的账户也可展示。没有 `account_context` 时，仍采用正现金起点及首收盘回撤为零的原有口径。

每日账户表展示估值时间、已确认负债、待登记后继权益、当日核定税款和实际扣收；税款明细保留事件、转让、核定和扣收 ID。一笔扣收分配多个核定时逐项展示。负债快照包含期初已有应付，不能用窗口内新增税款替代；净资产为总现金（含应收）加已登记持仓市值、加待登记权益、减负债。

税款核定确认税费及应付；扣收仅减少现金与应付，不再次减少净资产。两者单列，不并入交易费用图、成交费用或 TCA；交易印花税仍沿正式 `costs` 口径展示。账户快照和事件与七表共享报告预算；会话缺失、起点不一致或来源不匹配时拒绝生成账户报告。估值表声明 `cash_plus_positions_and_account_rights_v1` 时，缺少日频上下文或账户事实也会拒绝，不因验证状态为 fail 而退回现金起点。来源信息分别保存 `initial_cash_cny` 与 `opening_nav_cny`。报告展示封存事实及所引用的 VerificationResult 状态，不另行核定税款或扩大验证范围。

## 外部资金流与账户收益

日频股票与 ETF 可通过 `external_cashflows` 参数声明外部入出金。ResearchPackage 中该参数是完整 JSON 数组字符串，Python API 可传 `ExternalCashflow` 序列。目标模式与显式订单模式均使用同一现金账本；不声明资金流时沿用原收益口径。

每笔计划包含 `event_id`、`account_id`、`currency`、`direction`、`amount_units`、`requested_at`、`available_at`、`effective_at`、`status`、`reason` 和 `source_ref`。币种为 CNY，金额为正整数分；方向只允许 `deposit`、`withdrawal`，状态为 `settled`、`cancelled`、`failed`，失败或取消必须说明原因。账户身份必须与期初账户一致，无 `account` 时使用 `default`。事件 ID 不重复，同刻按输入数组顺序处理。

```yaml
external_cashflows: >-
  [{"event_id":"deposit-1","account_id":"default","currency":"CNY",
    "direction":"deposit","amount_units":20000000,
    "requested_at":"2024-01-03T09:00:00+08:00",
    "available_at":"2024-01-03T09:00:00+08:00",
    "effective_at":"2024-01-03T09:30:00+08:00",
    "status":"settled","reason":"","source_ref":"research-deposit-plan"}]
```

计划进入冻结参数和节点身份。受理时间为申请与可见时间的较晚者，生效不能更早。入金只在实际生效时增加购买力；出金受理时预占可提款现金，生效时重新核对约束，取消、失败或被拒绝时只释放本笔预占。交易订单预占、出金预占分别记录；当日卖出资金可用于交易，但在下一交易会话结算前不能提款，应收款及应付税款也影响可提款额度。

当前生效时点限定为已声明交易会话的上海时间 09:30 或 15:00，分别使用当时的原始开盘或收盘价格。持仓及待登记权益必须有相应可见估值，缺失时拒绝精确收益结果，不以未来收盘补算。每笔生效前后净资产、估值明细和事件顺序一并封存；失败与取消不改变净外部流量，也不增加收益切段。

有效资金流前先计算 `V_before`，生效后满足 `V_after = V_before + signed_flow`。无外部流量区间收益连乘得到时间加权收益；回撤使用调整后的净值，不使用入出金导致变化的资产规模。投资损益为 `期末净资产 − 期初净资产 − 净外部流量`。税费留在损益中；融资借入和还本不是本参数支持的资金流方向。

零净资产起步时等待有效注资后开启收益段；全额提款暂停收益段，再注资后继续连接已有有效收益。投资损失导致非正净资产时，整体收益标记 `not_applicable_nonpositive_nav`；尚未注资为 `waiting_for_funding`。不适用收益不生成数值指标，资金及损益事实继续保留。正式研究包应只请求可计算指标；若仍请求缺失收益指标，沿现有指标完整性门禁拒绝验收。零起点也不生成以期初净资产为分母的换手率。

带资金流的日频上下文为 `research-daily-cash-financial-context-v3`，其中 `external_cashflow_context` 使用 `research-external-cashflow-context-v1`：包含输入计划、金融事件、逐笔前后估值、会话收益序列及区间汇总。独立金融验证重新核对现金守恒、提款约束、可见价格和收益分段；Result 导出保留完整事实，恢复沿节点 checkpoint 边界，不重复应用入出金。

组合 HTML 从同一封存 Result 展示资金流调整后净值、回撤、资产规模、累计净入金、投资损益及逐笔前后估值。不适用区间留空并展示状态；最大回撤覆盖有效资金流边界及收盘观察，净值图按会话展示收盘点。

## 融资信用账户

日频算子通过 `account_model="financing_credit"` 与完整 JSON 参数 `credit_account` 声明融资账户，同时提供本页 `account` 和 `execution_mode="explicit_orders"`。缺省 `account_model="cash"` 保持普通现金行为。信用期初的账户身份、币种、时点与现货期初一致；所有金额为人民币整数分。融资仅支付绑定买单的实际成交款，费用由自有现金承担。

`CreditAccount.to_dict()` 输出完整声明，类型位于 `domain/credit_account.py`。空事实显式提供空数组，规则不能为空。字段包括：

| 字段 | 内容 |
| --- | --- |
| `contract_version/account_id/currency/cash_scale/as_of` | `research-credit-account-v1`、账户身份、CNY、精度2和带时区起点 |
| `rules` | 市场规则有效区间及可见时点、融资资格、担保折算率、保证金比例、授信、利率、日计数、追保及提款要求、来源和协议假设 |
| `contracts/position_links` | 逐合同未还本金、未付利息、计息余数、期限、原开仓规则，以及批次／后继权益／受限应收关联 |
| `order_allocations` | 融资买单与新合同、融资上限、自有资金上限、期限和来源 |
| `instructions` | 还款或展期、申请与可见／生效时点、状态及展期批准事实 |
| 协议计算方式 | `profile_id`、`repayment_link_policy`、`interest_policy`、`risk_sell_policy`、`sale_settlement_policy`，使用类型声明支持的明确枚举 |

首版使用2023-02-17及以后上交所 CNY 现金／证券融资规则范围。股票还需要前一会话市场担保品集中度、静态市盈率，以及当时的指数成份、风险警示、退市整理状态和来源等适用事实。担保折算区分上证180成份股、其他A股和零折算情形；没有历史事实不能依赖当前数据补齐。融资资格、折算率和协议参数按可见日期及有效区间选择，新订单不得装入期初旧合同沿用旧开仓比例。展期需要当时已可见的批准，每次期限同时满足协议天数及六个自然月限制。

授信及保证金在下单时预占，实际成交才形成债务；撤单只释放未使用额度。计息按协议自然日进行，保留不足一分的余数，未成交额度不计息。周末和假期仍按计息日期累计，利率变化按当时有效规则分段。融资卖出价款在结算前受限，结算后按声明顺序还本付息；卖出不足偿债时残余本金继续保存。现金部分还本按声明的比例分配本金关联，税务取得批次与融资关联分别维护。

现金、持仓与信用状态属于同一 Ledger。净资产为现金、证券及已确认应收权益，扣除融资本金、应计未付利息与其他负债。借款与还本不计投资者外部流量；计息减少损益，支付已计提利息不再减少损益。保证金余额、维持担保比例与净资产分别计算，不能互相代替。担保折算区分自有证券与融资关联资产，上涨折算和下跌全额亏损分别处理。

出金同时受已结算现金、订单／提款预占、应付负债及信用约束限制。债务存续时，提款前维持比例须严格超过协议提款线，提款后不得低于该线，协议提款线不得低于300%。风险通知、处置顺序与系统卖单进入事实记录，停牌、跌停和不可卖数量仍受公共撮合与结算规则约束；未解决到期债务或未完成违约处置不生成完整成功结果。

信用金融上下文为 `research-daily-cash-financial-context-v4`，其中 `credit_context` 版本为 `research-credit-account-context-v1`。它封存完整声明、逐事件本金／利息／关联、各观察时点估值、会话快照、风险命令和终态。六表估值模型为 `cash_plus_positions_and_credit_liabilities_v1`；原会话调整额继续包含待登记权益和其他负债，再扣除信用本金及未付利息。独立金融 oracle v11 从声明与原始金融事实复算，不能调用生产融资公式。

组合报告用信用净资产作为收益起点，分别展示未还本金、应计利息、已付利息、偿还本金、保证金余额、维持比例和风险事件；融资利息不混入成交费用或 TCA。收益使用封存的资金流调整序列，非正净资产保留不适用状态。导出 Result 携带完整上下文，离线报告无须访问原研究目录。

真实行情与明确的券商协议假设可以组成融资研究；额度、利率及账户批次是假设时，结果范围必须保留该说明。市场行情真实不代表真实客户协议已经复原。

## 已知范围

融资关联持仓的证券承接使用显式 `SecurityConversionPlan`，据其本金／现金／后继权益分配保持债务。普通公司行动入口的送转、拆并股、退市现金清算及代码迁移，当前没有专项信用本金承接合同，遇到融资关联持仓时拒绝执行；普通现金账户原有能力保持。

本页描述普通 CNY 现货日频账户及显式声明的融资信用账户。分钟资金流、分钟信用账户、融券和期货期初账户不由该入口开放。分钟股票的真实覆盖仍需要历史交易资格、停复牌、ST、限价及实际 PIT 工件来源，底层规则可表达不代表来源已获证。真实退市、换股及账户税务历史未齐全时，明确保留未验证范围；测试场景不替代真实来源。

## 无行情的非交易现金清算

`finance.simulation.daily-cash@1.0.0`可以声明`non_trading_sessions`，在没有行情和交易指令时推进退市现金清算。参数是JSON对象：

```json
{
  "dates": ["2006-05-26", "2006-05-29", "2006-05-30", "2006-05-31", "2006-06-01", "2006-06-02"],
  "available_at": "2006-05-25T15:00:00+08:00",
  "source_ref": "research-assumption://declared-non-trading-calendar"
}
```

日期必须严格升序、唯一，声明在首会话09:15前可见；`calendar_id`仍需填写。行情、目标和基准表保留固定schema，行情及交易指令为空。账户为显式期初普通现金账户，不接收融资或外部资金流。证券集合由`instrument_codes`及规则声明；首会话的v2退市现金动作退出全部旧持仓，随后由同一账本结算应收。未退出的非零证券持仓缺少报价时拒绝执行，不能填末价、零价或收购价为OHLC。

期初按已知收购权价值计量，到账只把应收转为现金，不重复确认收益。实际业务付款日、完成公告可见时间和研究确认现金可用时点应分别保存；保守确认不代表真实客户盘中可用性。金融上下文封存会话声明和空行情观察，独立验证核对会话覆盖、零成交、股份退出、应收到账及净资产。
