# 股票分钟 raw 成交量与 PIT 准入

理解股票原始分钟数据能支持哪些研究。

## 开始前

- 输入：当前股票分钟来源、实际结构和有界请求。
- 输出：来源身份、完成分钟准入和声明限制。
- 命令中的尖括号内容是待替换参数。

## 使用顺序

1. 使用当前股票分钟数据集。
2. 保持价格和成交量的 raw 口径。
3. 声明带时区的有界请求。
4. 通过 Catalog 和完成分钟准入。
5. 记录当前快照研究的结论限制。

当前发布合同已经与本地物理事实对齐：

- `cn_equity.minute_bar@3` 唯一绑定 `min1_stock`。
- 来源语义是 `raw + collected + pit_allowed`，不再提供旧的重建数据集。
- 价格和成交量字段只允许 raw 口径。
- `available.minute.completed_bar.v1` 只允许已经完成的 bar 进入正式研究。

`package admit` 不要求调用方提供供应商历史版本清单。该类清单无法恢复仓库没有保存的旧版本，也不能证明供应商从未修订。准入检查当前 Catalog binding、实际 schema 和带时区的有界 QueryIR。`as_of` 必须不早于 bar 完成时点。输入还必须满足稳定主键排序和 `raw + collected + pit_allowed` 语义。

Runtime 继续记录本次实际读取的来源 revision 和内容身份。其用途是判断能否恢复旧 checkpoint、比较两次结果和解释输入变化。它不能反推出供应商在历史当天保存的版本。

## 结论上限

股票 raw 分钟可以支持“基于当前保存供应商快照的历史研究观察”。不能声称精确重放供应商历史当天版本。若某个研究必须精确重放，研究项目需要在运行前保存版本化查询切片或来源快照。如果过去未保存版本，精确重放缺少依据。禁止倒填 `available_at`。

raw bar 的准入不放宽其他 PIT 输入：

- 前复权、后复权仍需要决策时点可见的因子快照。
- 成分、ST、上市状态、行业、市值、停牌和市场规则仍需要历史快照或有效区间。
- `AUDIT` 只允许用于观察，例如扫描、对账和重采样，不能流入 Feature、Label、Signal、Statistics 或交易仿真。
- 正式消费读取已发布的 Result。可见时间和交易规则由实际生产入口执行。

## 与采集审计的分工

采集侧的 raw/pre/post 远端抽样、marker 和分钟文件对账用于发现采集或复权口径差异。它们不会自动修改 DuckDB、Parquet 或 Catalog，也不作为每次研究的硬门禁。抽样失败应回到采集任务调查数据内容。

Catalog/schema/completed-bar 失败则回到 ResearchPackage 准入修正合同。两类问题的消费者和处理动作不同，不能用一次远端抽样代替研究准入。也不能用 Catalog 通过证明供应商绝对正确。


## 常用名称

| 名称 | 含义 |
| --- | --- |
| ResearchPackage | 数据、算法、样本、指标和预算的完整声明 |
| Catalog Lock | 已确认的字段、来源和可见性说明 |
| PIT（按时点可见） | 过去某时刻只使用当时已知的信息 |
| bar（周期行情） | 一个日线或分钟区间的行情记录 |
| OHLCV（开高低收量） | 开盘价、最高价、最低价、收盘价和成交量 |
| Feature（特征） | 决策时已知的研究输入 |
| Label（标签） | 用于评价预测的未来目标 |
| bundle（封存包） | 完整代码、依赖或数据声明及其内容身份 |
| checkpoint（检查点） | 通过验收的节点输出和恢复依据 |
| Result（正式结果包） | 正式表、运行摘要及配置、实现和输入引用 |
| minute_scope（分钟范围引用） | 指向同一冻结日历和历史规则的小引用 |
| Supervisor | 监督运行和提交结果的主进程 |
| Worker | 执行节点计算的独立进程 |
