# 分钟特征、标签与信号算子

计算因果特征、未来标签和阈值信号。

## 开始前

- 输入：已准入、完成且质量合格的一分钟行情。
- 输出：独立的特征、标签、信号或数量目标工件。
- 命令中的尖括号内容是待替换参数。

## 使用顺序

1. 选择已登记算子。
2. 声明窗口、缺口与会话政策。
3. 把标签分支与特征和信号隔离。
4. 准入完整计算图。
5. 按可见时点消费输出。

分钟算子只接受 ResearchPackage 中的声明和已经通过 Catalog、PIT、session、质量门禁的数据工件。不读取数据库，也不接受 SQL、Python、模块路径或任意表达式。

## 受控算子

| 算子 | 输入 | 输出 | 主要边界 |
| --- | --- | --- | --- |
| `research.bars.minute_resample@1.0.0` | 标准 1m bar | 1m bar | 保留来源引用，按历史交易时段规范化一分钟行情 |
| `research.features.intraday@1.0.0` | 完整、质量通过的 bar | 分钟特征 | 仅滞后收益、滚动波动、量比、VWAP/close 偏离 |
| `research.labels.intraday@1.0.0` | 完整、质量通过的 bar | 未来收益标签 | entry、exit、horizon、overlap 明确进入身份 |
| `research.signals.intraday@1.0.0` | 分钟特征 | 离散信号 | 仅大于/小于阈值，不可读取标签 |

本页的算子都在唯一`OperatorDefinition`清单登记。另有`research.targets.intraday@1.0.0`将离散信号转换为数量目标，其工件不提供独立策略撮合入口。行情、特征和标签的 `interval_minutes` 固定为1。

5、15、30、60、120分钟在声明或计划构建时拒绝。窗口、warmup、缺口、跨 session、复权、资产类别和可见性策略仍为声明参数。参数变化会改变计划和节点身份。

日线直接使用日频来源，不从分钟聚合。

## 时间与前视边界

特征和信号只能读取 `completed=true`、`quality_status=pass` 且 `available_time <= decision_time` 的行。默认滚动窗口不跨 session。显式允许跨 session 时仍按单一标的稳定排序。缺口只能选择失败或重置窗口，不做插值。

标签的 `available_time` 是退出事件实际可见时间，不是信号决策时间。标签工件使用独立 artifact type，编译器还会遍历依赖图，拒绝任何 `label → feature/signal` 的直接或间接边。`next_bar_open` 从下一根 bar 开盘开始计算，不会误用决策 bar 已经发生的开盘价。

当前集合刻意保持很小。新增 feature 必须同时补齐口径、时间可见性、资产适用范围、确定性测试和参考包需求。不能通过通用表达式绕过白名单。

`minute_line.complete` 保持有界本地 `local_only`。股票和ETF策略使用LEAN，指数仅作非交易benchmark。期货参考包保留一分钟数据研究，人民币期货按[期货执行合同](lean-futures.md)准入与执行。历史Result沿用各自冻结范围。

## 项目因果分钟与日级模型交接

已准入的项目Feature可直接消费 `data.minute-bars.1m.v1` 原始分钟工件。观测和可见时间绑定实际分钟dt，核心按冻结窗口交付completed bar并记录实际来源事实。

带冻结ResearchSemantics的正式Feature/Label，如果输出使用完整公共日级行键。且 `observation_session` 为Arrow日期类型，核心会按日级模型工件封装。Feature行键为 `entity_id, observation_session, window_sessions, feature_id`。

Label行键为 `entity_id, observation_session, horizon_sessions`。工件保留键批分区、表身份、causal_plan和semantics_hash，模型通过同一正式loader读取。来源使用raw分钟dt时，也适用该输出合同。

显式 `stateless_session` 的归档读取按冻结文件清单建立观测列与行组时间边界索引。每个键批先按声明分区及真实窗口选择文件，再由8句柄上限的只读缓存打开实际候选。文件路径命名不参与时间判断。

未知行组统计保留读取，最终PIT裁剪、原文件与行组顺序及输出schema不变。会话逐批核对索引来源文件的大小与修改时间，变化时拒绝继续。索引不保存行情行。

普通事件行键保留原有Parquet提交。无ResearchSemantics且不声明daily_time的低层执行不进入日级模型封装。既有daily_time绑定仍要求冻结ResearchSemantics。该封装不改变原始来源、时间裁剪、缺失资格、金融公式或Label成熟规则。


## 仿真行情列投影

`execute_minute_resample(source, plan=..., columns=...)`可声明输出列。省略时输出完整标准列。源行情的顺序、数值、会话与可见范围检查保持，状态计数在投影前完成。

内部只构造请求列及状态计数必需的`bar_status`列，未请求的源字段仍执行数值和质量检查。未请求`session_hash`时，按原日历解析历史政策、交易日期和时段，不构造完整会话及其政策摘要。请求该列时仍生成完整身份。

两条路径共用同一历史选版和唯一时段检查。

仿真规范化入口只请求实际使用的行情列，以65536行为上限交付排序。正式事件仍按可见时点逐帧消费，更大的读取批次不扩大策略可见窗口。


## 冻结日历加载

分钟范围重建保留全部政策版本、证券身份、证据链和历史可见时间。日历 bundle 校验在本次调用内复用相同政策正文的规范字节。逐条加入证券身份，并用完整内容计算原 bundle 摘要。

模板按完整正文区分日期、时段、可见时间文本和证据。序列化仍返回独立容器。

## 标签的经济时间

`label_start`与`label_end`记录起价和终价对应的实际事件：开盘价使用bar_start，收盘价使用bar_end。统计使用这些时点推导重叠窗口、HAC和embargo下限，午休、隔夜与跨会话间隔保留实际经过时间。

已知收盘价作为起点时，经济起点可以等于或早于决策时点。终价须晚于决策和起点。第一条真实未来观测必须严格晚于决策，已知起价不计入未来观测。

标签available_time保留实际退出数据的可见时间。研究标签的起价事件不改变LEAN成交时钟。


## 项目分区的批量质量检查

普通项目分钟分区按有界RecordBatch检查股票类行情。代码与时间的严格排序、重复、缺失、成交量有限非负和完成分钟时段采用数组计算。跨批次保留上一行及当前证券日计数，一分钟输入仍要求每天恰好240根。

完整消费后才形成质量回执，缺失证券日不能因批次边界被跳过。批量处理不扩大来源范围或策略可见时间。

带时区输入先转换为准入来源墙钟。期货继续按冻结日历逐条解析实际交易日和会话。该读取层只处理通用行情质量，不包含项目因子公式。


## 常用名称

| 名称 | 含义 |
| --- | --- |
| ResearchPackage | 数据、算法、样本、指标和预算的完整声明 |
| Catalog Lock | 已确认的字段、来源和可见性说明 |
| PIT（按时点可见） | 过去某时刻只使用当时已知的信息 |
| bar（周期行情） | 一个日线或分钟区间的行情记录 |
| OHLCV（开高低收量） | 开盘价、最高价、最低价、收盘价和成交量 |
| Feature（特征） | 决策时已知的研究输入 |
| Label（标签） | 用于评价预测的未来目标 |
| bundle（封存包） | 完整代码、依赖或数据声明及其内容身份 |
| checkpoint（检查点） | 通过验收的节点输出和恢复依据 |
| Result（正式结果包） | 正式表、运行摘要及配置、实现和输入引用 |
| minute_scope（分钟范围引用） | 指向同一冻结日历和历史规则的小引用 |
| Supervisor | 监督运行和提交结果的主进程 |
| Worker | 执行节点计算的独立进程 |
