# 分钟参考规则来源边界

QuantWitness 随包提供的分钟规则 bundle 是一个窄范围参考快照，用来验证时间可见性、规则解析和仿真拒绝路径。它不是全市场规则库，也不表示框架能够直接覆盖任意标的、日期或实盘账户。

## AG2406 reference boundary

`AG2406.XSGE` 参考范围只覆盖 2024-01-03 至 2024-01-04。合约单位、最小变动价位和交割规则来自随 bundle 列出的上期所公开资料；费率、保证金、结算价和实际合约映射来自冻结时已经完成的本地只读观察。原始供应商数据不随框架分发，因此这些值的声明上限保持为 `research_observation`，不能外推到其他日期、其他合约或历史实盘决策。

规则的 `available_at` 是框架用于拒绝前视读取的可见性边界。冻结窗口之外没有默认值；缺失、重叠或晚于决定时点的规则必须失败。

## ETF reference boundary

`510300.XSHG` 参考范围只覆盖 2024-01-02 至 2024-01-05。交易单位参考随 bundle 列出的上交所公开规则；ETF 类别、生命周期、T+1、前收观察和研究费用口径来自冻结时完成的本地只读观察。原始供应商数据不随框架分发，研究费用也不代表任何真实券商账户。

价格限制由前一交易日已经完成的前收观察和 bundle 中声明的规则推导；同日日线只用于事后核对，不得成为盘中或盘前输入。PIT 复权仍由研究自己的显式快照负责，不能从这个参考 bundle 推断。

## 分发边界

公开仓库只分发规则合同、窄范围参考值、官方定位符和上述限制说明，不分发市场数据库、供应商导出或内部任务记录。扩展资产或日期需要先扩展平台准入能力，再发布可追溯规则 bundle，并把来源、有效期、可见时点和声明上限一起冻结。
当前平台能力只准入随包参考窗口，期货分钟分区会携带当前发布 bundle 的身份；项目 Worker
必须核对这一身份，不能在没有准入覆盖时换用另一份本地规则或回退到默认时段。
