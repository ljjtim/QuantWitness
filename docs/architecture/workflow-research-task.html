研究流程

独立 lint 是主动诊断；普通 execute 不重复完整准备。

节点职责

展开节点查看当前行为与边界。

研究问题与约定

确认公式和研究边界。

完整研究包

填写四份声明与输入；lint可主动诊断缺项。

准备与准入

一次解析、编译、检查并交接对象。

执行 DAG

发布合格 checkpoint，记录资源与真实进展。

发布 Result

封存正式表、模型和必要来源引用。

报告与开发反馈

直接 Result 交付；报告失败不重跑金融。

最终评价

单独确认候选后消费持久留出，打开后失败不返还。

交接关系

  • 研究问题与约定 → 完整研究包：声明
  • 完整研究包 → 准备与准入：execute
  • 准备与准入 → 执行 DAG：计划
  • 执行 DAG → 发布 Result：成功输出
  • 发布 Result → 报告与开发反馈：直接消费
  • 报告与开发反馈 → 最终评价：选定候选
