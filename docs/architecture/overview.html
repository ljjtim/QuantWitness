总体概览

研究声明、一次准入、执行与直接交付。

节点职责

展开节点查看当前行为与边界。

个人研究问题

冻结问题、公式、样本与预算。

可选 AI 提案

RD-Agent 读取成功 Result 的开发指标，最终留出不进入循环。

ResearchPackage

保存来源、日期、算法、指标、时点与资源声明。

一次准备与准入

同次解析和编译对象直接交接；检查实际来源与 PIT。

计算或回测

模型由 Qlib 执行，分钟策略由 LEAN 执行。

Result

发布正式表、指标、摘要和持久来源引用。

报告与反馈

直接读取 Result 生成报告、比较或下一轮开发反馈。

交接关系

  • 个人研究问题 → ResearchPackage：确认范围
  • 可选 AI 提案 → ResearchPackage：候选
  • ResearchPackage → 一次准备与准入：完整声明
  • 一次准备与准入 → 计算或回测：计划
  • 计算或回测 → Result：原子发布
  • Result → 报告与反馈：直接消费
  • 报告与反馈 → 可选 AI 提案：开发指标
