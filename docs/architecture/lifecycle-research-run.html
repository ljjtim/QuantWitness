运行状态

节点、运行和结果组装各自保留真实状态。

节点职责

展开节点查看当前行为与边界。

已准入计划

固定输入、实现、参数与预算。

节点执行

queued/running与心跳不代表输出成功。

成功 checkpoint

内容、资源与交接合格后才能复用。

中断或节点失败

同身份resume或允许的retry；更改声明后重新准入。

Result组装

全部节点成功但组装失败时只重试组装。

Result已发布

结果只读，补齐completion与索引不重跑节点。

报告或导出

结果消费失败后只重试交付，不重复训练或holdout。

交接关系

  • 已准入计划 → 节点执行：启动
  • 节点执行 → 成功 checkpoint：提交成功
  • 节点执行 → 中断或节点失败：失败
  • 中断或节点失败 → 节点执行：合法恢复
  • 成功 checkpoint → Result组装：全部完成
  • Result组装 → Result已发布：原子发布
  • Result已发布 → 报告或导出：直接读取
