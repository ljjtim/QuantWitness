数据追溯

来源、时点、算法和结果由正式对象关联。

节点职责

展开节点查看当前行为与边界。

原始来源

数据库只读；输入归档与数据库来源互斥。

Catalog Lock

固定字段、物理绑定和可见性规则。

准入计划

冻结请求、日期、参数、clock、seed和实现引用。

列式输入 / 工件

保留必要历史版本，按预算有界读取。

算法 / 交易节点

实际消费处限制 PIT、标签、资金与历史规则。

Result

正式表、指标、模型及配置和持久输入引用。

报告 / 分析 / 导出

ResultContext直接读取所需列；原始持久依赖随归档保留。

交接关系

  • 原始来源 → Catalog Lock：物理来源
  • Catalog Lock → 准入计划：批准绑定
  • 准入计划 → 列式输入 / 工件：请求范围
  • 列式输入 / 工件 → 算法 / 交易节点：当时可见数据
  • 算法 / 交易节点 → Result：正式输出
  • Result → 报告 / 分析 / 导出：按需投影
