模块职责

箭头表示主要交接，模块内部依赖以源码为准。

节点职责

展开节点查看当前行为与边界。

CLI / Workspace

application 组织准备、准入、运行和恢复。

packages

解析 ResearchPackage、编译 QueryIR、图和指标。

catalog

字段、物理来源、历史可见性和 Catalog Lock。

data_plane

只读数据访问、归档输入和有界列式物化。

runtime

执行依赖图、监管资源、提交 checkpoint。

research

特征、标签、统计、Qlib模型与留出账本。

domain / simulation

实际交易转换处处理资金、持仓、费用、规则和公司行动；分钟项目使用 LEAN。

results

原子发布 Result，提供 ResultContext。

报告 / AI / Dashboard

读取正式结果；evidence 提供分析与研究范围事实。

交接关系

  • CLI / Workspace → packages：准备
  • packages → catalog：来源准入
  • catalog → data_plane：绑定
  • packages → runtime：执行图
  • data_plane → runtime：列式输入
  • runtime → research：研究节点
  • runtime → domain / simulation：金融节点
  • research → results：模型与指标
  • domain / simulation → results：交易事实
  • results → 报告 / AI / Dashboard：直接交付
