总体概览

RD-Agent 提出候选；QuantWitness 按声明准备、准入与执行，Result 直接用于报告和开发反馈。

总体架构

14 个核心模块如何分工，RD-Agent、Qlib、LEAN 和研究数据从哪里接入。

数据追溯

把只读来源、执行约定、实际输入和正式 Result 的消费串起来。

研究流程

一次准备与准入、执行与 Result 交付；发生中断时按原执行恢复。

调用时序

只读来源交接、节点执行、Result 原子发布与直接交付。

运行状态

运行成功后如何发布 Result，中断或交付失败时怎样接续。
