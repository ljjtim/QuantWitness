调用时序

同次对象交接与跨进程持久计划分别处理。

节点职责

展开节点查看当前行为与边界。

execute_workspace

分配或接续原 execution。

prepare_package

解析和编译一次，交接已准备对象。

admit_package

检查实际来源、结构和可见性，发布计划。

RuntimeExecutionService

调度有界 Worker，消费合格输入并保存 checkpoint。

ResultAssembler

节点成功后发布 Result；组装失败可恢复。

load_result_context

加载正式输出、指标、结论范围和限制。

report / compare / export

按需读取正式表，直接交付研究结果。

交接关系

  • execute_workspace → prepare_package：准备
  • prepare_package → admit_package：同一对象
  • admit_package → RuntimeExecutionService：持久计划
  • RuntimeExecutionService → ResultAssembler：typed输出
  • ResultAssembler → load_result_context：Result位置
  • load_result_context → report / compare / export：ResultContext
