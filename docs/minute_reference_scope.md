# 分钟数据与参考范围

查看随包分钟材料覆盖的证券和范围。

## 开始前

- 输入：当前能力清单、会话和规则 bundle。
- 输出：受支持范围与待补充的来源要求。
- 命令中的尖括号内容是待替换参数。

## 使用顺序

1. 按资产类型查找参考证券。
2. 核对实际日期和规则覆盖。
3. 缺少材料时声明自有来源。
4. 按正式主链准入。
5. 根据当前范围解释结果。

公开分钟行情、特征和标签只接受`interval_minutes=1`。日线直接使用日频来源。分钟数据须为当前Catalog准入的`raw + collected + pit_allowed`，具有实际schema、带时区的有界请求、稳定排序和completed bar。

## 随包材料

`src/research_pipeline/platform/minute_capabilities/minute_capability_manifest.v3.json`描述随包参考标的、资产类型、来源语义、时段和规则要求。会话与规则分别由当前v6 bundle提供。加载器核对发布身份、资产分类、来源及请求范围。数据存在不能代替完整交易规则。

| 资产 | 参考证券 | 数据用途 |
| --- | --- | --- |
| 股票 | 000001、600000、300015、688981、300784 | 一分钟行情与PIT研究输入 |
| ETF | 510300、511010 | 一分钟行情与PIT研究输入 |
| 指数 | 000300 | 非交易benchmark |
| 期货 | AG2406、AG2412、IF2401、T2403 | 一分钟数据研究与会话观察 |

参考来源的日期、会话与必需规则以manifest及bundle为准。随包股票、ETF规则仍有unsupported项，不能据此直接运行任意证券或区间。参考期货规则和数据不构成当前期货策略执行能力。

## 自有证券与日期

A股项目可通过包内`minute_scope`提供完整历史日历、规则版本及来源。将实际证券和日期交给同一准入流程，不必等于随包窗口。规则按生效日期和当时可见时间选择。

前收与价格限制逐日覆盖。完整声明见[项目分钟范围](minute-project-scope.md)。ETF、指数和期货仍遵守各自已发布来源及覆盖要求。

原始分钟只使用当时已完成记录。复权研究另消费可见因子和公司行动快照。raw行情的准入不证明供应商保存了历史当天的每个版本。

也不放宽ST、成分、行业、停牌及市场规则的历史可见性。`AUDIT`只作观察，不进入Feature、Label、Signal、Statistics或交易执行。

## 策略与结果

股票和ETF日线、一分钟策略统一使用[LEAN执行](lean-execution.md)。一分钟委托按后续完成分钟Close加声明滑点成交。正式simulation保存orders、intents、daily、trace和metrics，以及账户与策略支持文件。行情、规则、公司行动及信号保留持久工件与计划引用。

分钟算子见[分钟特征、标签与信号](minute_operators.md)。规则结构见[分钟市场规则](minute_market_rules.md)，来源及公司行动见[分钟规则来源](minute_rule_provenance.md)。能力状态仅描述相应本地实现范围，不表示全历史、全市场、tick、盘口或实盘认证。


## 常用名称

| 名称 | 含义 |
| --- | --- |
| ResearchPackage | 数据、算法、样本、指标和预算的完整声明 |
| Catalog Lock | 已确认的字段、来源和可见性说明 |
| PIT（按时点可见） | 过去某时刻只使用当时已知的信息 |
| bar（周期行情） | 一个日线或分钟区间的行情记录 |
| OHLCV（开高低收量） | 开盘价、最高价、最低价、收盘价和成交量 |
| Feature（特征） | 决策时已知的研究输入 |
| Label（标签） | 用于评价预测的未来目标 |
| bundle（封存包） | 完整代码、依赖或数据声明及其内容身份 |
| checkpoint（检查点） | 通过验收的节点输出和恢复依据 |
| Result（正式结果包） | 正式表、运行摘要及配置、实现和输入引用 |
| minute_scope（分钟范围引用） | 指向同一冻结日历和历史规则的小引用 |
| Supervisor | 监督运行和提交结果的主进程 |
| Worker | 执行节点计算的独立进程 |
