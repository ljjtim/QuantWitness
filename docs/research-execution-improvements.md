# 研究执行与验证

框架把运行是否存活、是否有实际进展、结果是否发布和独立验证是否通过分别记录。观察信息帮助判断等待与资源使用，正式恢复和研究结论仍以计划、checkpoint、Result 与 VerificationResult 为依据。

## 执行与恢复

- [真实进度](runtime-progress.md)记录已经提交或复用的 DAG 节点、成功封口的因果批、最近有效进展和吞吐。心跳不计作完成量；有至少两个批耗时样本时才给当前批阶段的 ETA 范围。
- [Workspace 接续](workspace-continuation.md)用显式 execution_id 找到原执行，委托原有恢复、验证和报告服务。已有正式验证可复用，所消费产物损坏、绑定不一致或恢复依据不足时拒绝重新启动研究。
- [资源预算](project_resource_budgets.md)保留节点与验证额度，展示已知输入文件体积、声明容量和进程启动开销。预估缺少依据时显示 unknown，不自动增加预算。
- 完整研究包通过 Workspace 模板复用，参数变体只替换已有声明；数据时点、图、金融合同和 holdout 边界仍须通过正式准入。

## 验证的数据表示

模型事实绑定直接保留 Arrow 列和按需读取的行视图，不把所有单元格展开为长期驻留的 Python 字典。样本表只绑定原有验证所需列，其他核对表继续保留完整字段；重复键、时间、金融指标和原有证据检查保持一致。holdout 预测收据逐行使用原 typed canonical 编码，避免同时保留另一份完整 JSON 行列表。

项目 Verifier 可[声明授权列](verifier-input-projection.md)，按批投影到独立输入文件，正式原表仍作完整性核对。未声明投影的表继续完整复制。输入声明随 bundle 身份冻结，缺列或资源不足会失败，不以抽样替代完整独立复算。

已验证结果的接续通过原 VerificationResult 与 Result 绑定关系复用已有结论，避免重复训练和独立复算；这不改变新结果必须验证的要求。

## 实现边界

框架测试使用合成公共合同；研究项目的脚本接线测试留在项目。实现身份按入口文件、适配器族及显式依赖绑定，清单外文件变化不改变局部源码身份，真实依赖变化拒绝旧 checkpoint。分钟有效性入口单独记录其独立重算模块，不影响相邻统计入口的依赖清单。[身份范围](implementation-identity-scope.md)说明局部源码身份与整构建恢复约束的差别。

这些能力接收通用研究包、schema、节点、列声明和执行标识；指数代码、证券数量和策略参数属于研究项目。

## 有界测量

| 测量对象 | 原表示 | 新表示 | 说明 |
| --- | ---: | ---: | --- |
| 50,000行、14列：绑定新增 Python 峰值 | 56,683,232字节 | 5,855字节 | 相同的5,988,890字节 Arrow 表仍驻留；不代表总RSS |
| 同一输入：建立行表示耗时 | 1.234秒 | 0.000298秒 | 只测绑定，不代表完整 verify |
| 同一输入：单列遍历耗时 | 0.00563秒 | 0.04792秒 | 按需读取单元格增加访问开销，求和结果一致 |
| 8,192行、64列：Verifier 单列输入文件 | 4,260,164字节 | 34,029字节 | 复制量减少99.20%，取决于实际选列及压缩 |

模型测试覆盖行序、日期、空值、嵌套值、重复键拒绝、收据一致和合成正式模型判定。投影测试覆盖身份冻结、列和值、缺列拒绝、空间预算、空分区及原文件隔离。接续测试覆盖原运行恢复、已有验证复用、失败不覆盖和 holdout 不重复；进度测试覆盖实际 Worker 成功批、失败批和 checkpoint 复用。测试使用文件和合成输入。

## 已知限制

模型拟合内部、输出组装和独立验证尚无统一细粒度完成量；当前因果批 ETA 不包含后续阶段。Arrow 原始数据和必要的键索引仍占内存，行视图不保证所有验证算法恒定内存。投影重编码有计算开销，宽表少列最容易获益，完整模式仍复制完整输入。共享源码文件变化可能影响使用它的多个入口；长任务应使用保持不变的独立安装环境，可编辑安装没有自动物理冻结。

以上改进降低执行与验证的额外开销，不改变策略收益或证明新的金融增量。
