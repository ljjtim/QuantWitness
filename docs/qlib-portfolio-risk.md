# 把预测变成有约束的持仓目标

预测给出排序或分数，组合构建决定每只证券配多少。这里复用 Qlib 的风险估计和优化组件，在声明的约束内计算目标；成交、费用与账户变化继续交给正式仿真。

求解成功不是策略盈利证明。求解失败、数据不足或约束不可满足，应体现在结果与诊断中。

## 参数与行为说明

组合风险使用[项目扩展](../project_extensions/qlib_portfolio_risk/README.md)进入正式ResearchPackage。风险估计、目标优化、现金执行及报告各保留自己的输入和输出。

## 数据与金融口径

协方差采用Qlib 0.9.7的RiskModel和ShrinkCovEstimator。经验协方差先去均值，再以会话数N为分母；固定收缩alpha=0.1、常方差目标。收益单位为小数，不乘100、不年化。每个历史收益及其成熟时点必须在决策时可见，完整窗口必须覆盖固定证券集合。

普通优化支持逆波动、最小方差、风险平价和均值方差；只做多并满仓。均值方差区分预期收益与标准化分数，缩放选择进入配置。双边换手为sum(abs(w-w0))，与实际成交换手分别报告。逆波动不支持换手约束。

增强指数优化超额收益减去风险惩罚，使用因子暴露、因子协方差和残差方差。基准偏离、因子偏离、强制持有、强制卖出和换手预算进入约束；强制卖出覆盖同证券的强制持有，沿用固定Qlib方程。

TopkDropout使用bottom/top筛选和实际持有会话数。保留持仓维持实际权重，新买证券均分可用资金乘risk_degree，剩余作为现金；持有期限可能阻止计划卖出。交易限制由现金引擎处理。

## 求解状态与最终目标

SciPy与CVXPY返回的实际状态分别保存。默认只接受原约束成功且最终残差在容差内的目标。显式允许换手放宽时，每次尝试单独记录放宽项；失败保留原持仓仍记录对当前约束的残差。返回权重等于原持仓不能作为回退判据。

增强指数先按epsilon截断小权重，再归一化，随后复核长仓、满仓、换手、基准和因子暴露约束。后处理越界产生postprocessing_rejected；目标不能进入执行。全相同分数的缩放与逆波动零波动输入明确拒绝。

风险方法、估计器及窗口进入冻结设计，模型拟合与最终holdout绑定同一设计。Result保存risk_inputs、risk_optimization_results、risk_optimization_attempts、risk_constraint_residuals及targets/benchmarks，包括证券、可见时点、求解器版本、状态、目标、约束和回退。开发测试手算风险矩阵、目标值及约束；金融执行使用daily-cash的实际资金、费用和TCA口径。

## 验收与范围

[公开示例](../examples/qlib_risk/README.md)用合成Parquet和初始全现金状态完成单次调仓。四种普通组合有直接Qlib对照与手算；增强指数覆盖原问题可行、强制卖出冲突、显式放宽、求解报错、原持仓正好最优、截断后越界；现金验收覆盖六种方法及停牌导致的目标/成交差异。

动态多次持仓反馈、真实基准和真实风险因子快照需要在研究包中另行声明。组合数值和目标可行性不证明策略盈利。项目扩展不申请公共算子晋级。
