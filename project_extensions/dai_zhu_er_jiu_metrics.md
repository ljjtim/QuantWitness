# 待著而救指标合同

当前 ResearchPackage 的 MetricContract 版本为 `v2`。统计数值算法保持一致，覆盖率和分组成员变化使用明确的指标身份与分母定义。

| 指标 | 正式身份 | 计算口径 |
| --- | --- | --- |
| 因子收益配对覆盖率 | `factor.coverage@2.0.0` | 当月有限因子与收益配对数 / 当月输入全集证券数，再对有效评价月等权平均 |
| 分组成员变化比例 | `factor.membership_change_mean@1.0.0` | 相邻有效评价月的进出证券数加跨组证券数 / 前后成员并集证券数，再对相邻评价期等权平均 |
| 高组减低组收益差 | `factor.group_return_spread@1.0.0` | 最高组减最低组下一月收益，按有效评价月等权平均 |
| IC 均值 | `factor.ic_mean@1.0.0` | 月末因子与下一月收益的截面 Pearson 相关均值 |
| Rank IC 均值 | `factor.rank_ic_mean@1.0.0` | 月末因子与下一月收益的截面 Spearman 相关均值 |

覆盖率的输入全集包含股票池不合格、因子不可用、缺少有效收益的证券。小市值包的分母同样来自进入分析的输入全集，不是市值过滤后的合格池。此指标需要下一月收益完成后才能计算，不能在信号日当成可用特征。

分组成员变化只衡量证券进出和组别变动。前期 `{A:1, B:2, C:2}`、后期 `{B:1, C:2, D:2}` 时，A退出、D进入、B跨组，变化比例为 `3/4`。它不读取组合权重、成交金额或费用，不表示交易换手率。明细表沿用 `*.turnover.v1` schema 和 `turnover` 列，列内数值含义就是此处的成员变化比例。

不足最小截面或因子、收益为常数的月份不进入有效评价月。成员变化比较相邻的有效评价月；存在被跳过月份时，不假设两期在日历上连续。首个有效评价月没有成员变化值。

## 独立验证

独立统计 Verifier 为 `dai-zhu-er-jiu-factor-check@2.0.0`，公式与统计联合 Verifier 为 `dai-zhu-er-jiu-formula-and-statistics-check@3.0.0`。单独公式 Verifier 保持 `dai-zhu-er-jiu-fixed-session-formula-check@2.0.0`。

统计复核从冻结的 verifier identity 读取 MetricDefinition，核对两项指标的数量含义、分子、分母、观察时间、聚合方法及单位。覆盖率分母由标签资格审计逐月统计，分子由分析成员明细复算；成员变化由相邻期成员与组别复算。声明错误、明细错误或正式指标与重算值不一致时，验证失败。

历史 Result 保留原有指标、Verifier 身份和封存内容。新包使用新合同构建与准入，历史运行的恢复和复验仍绑定当时的冻结材料。新旧指标不能仅按相同的数值视为同一合同。
