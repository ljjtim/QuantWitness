# 独立金融复核

日频现货的价格与历史规则由 `daily_etf.py` 核对，账户批次、应收、税权和到账现金由 `spot_account.py` 从期初事实及封存事件独立重建，六表守恒由 `canonical.py` 核对。

非交易日频现金清算使用 `non_trading_cash.py` 独立解析顶层 `non_trading_sessions`：`dates` 为非空、严格升序且唯一的 ISO 日期列表，`available_at` 为带时区时间且严格早于首会话上海时间 09:15，`source_ref` 为非空来源。

该路径绑定目标模式 v1 或无命令显式模式 v2 日频现金上下文及期初账户，封存行情为空，订单、成交与成交费用为空。现金和估值必须完整覆盖声明日期，持仓记录须属于声明会话和规则证券且数量、市值与全部桶均为零；每会话估值时间为上海时间 15:00。期初账户须有非零证券持仓；首会话以已可见的 v2 退市现金行动清除期初持仓，顶层行动须与账户封存源事实一致。持仓退出后不要求旧证券继续提供报价。

声明纳入现有 `context_hash`。账户 oracle 继续独立核对退市应收、到账、成本注销、重复支付及净资产，金额复算不调用生产金融计算。研究参数和封存事实的绑定沿用项目 Verifier。

历史规则须覆盖声明日期，并在各会话上海时间 09:15 前可见。无命令显式模式的会话终点须与声明日期及收市时间一致，命令、订单事件、观察、费用和命令规则均为空。

正式六表沿用稀疏持仓合同，零数量且零变化的行可以省略。账户 oracle 在每个声明会话独立重建批次和数量，确认缺省持仓确实为零。

退市现金清算使用生效时的实际持仓，不要求登记截止日在期初之前的账户补造登记权利。转让数量、批次成本注销与到账金额分别独立核对；齐鲁日期组合为 2006 年 5 月 25 日截止、5 月 26 日转应收、6 月 2 日到账。
