# 换手率低值五分组入门

本例参考华泰证券的《华泰单因子测试之换手率类因子》。报告发表于 2017 年 1 月 9 日。本例按历史平均换手率由低到高分组，再观察未来收益。教程使用20只合成证券、9个合成交易日，只演示分组研究流程。原报告包含12项因子，本例没有重现其全部实验，也不执行交易。

## 运行

先在公开源码根目录安装框架，然后指定一个尚不存在的输出目录：

```powershell
python -m pip install . "pyarrow==21.0.0"
python examples/turnover_factor/run.py --output ../quantwitness-work/turnover-first
```

脚本构建项目算子与完整ResearchPackage，生成独立Catalog和Parquet输入，执行正式`package admit → run → Result`，最后从Result生成`report.md`与`receipt.json`。不连接数据库，不读取私人文件，不调用远端服务。wheel不包含示例源码，运行本例需要完整源码或解压后的sdist。

## 公式与时间

观察日为`t`，窗口固定为前3个交易日，**不包含`t`**：

`平均换手率(i,t) = [换手率(i,t-3) + 换手率(i,t-2) + 换手率(i,t-1)] / 3`

前一交易日字段按下一交易日开盘可见。每个观察日按平均换手率升序排列合格证券。合格证券必须有完整窗口。同值证券按代码排列。第`rank`个证券分组为`floor(rank × 5 / N) + 1`，rank从0开始。20只证券每组4只，组1为低换手率组。

标签由独立函数计算：`未来收益(i,t) = 收盘价(i,t+1) / 收盘价(i,t) - 1`。它只用于事后评价，不参与资格、窗口和排序。最后一天仍保存分组，标签为空。

每日观察值为组1等权平均未来收益减去组5等权平均未来收益。正式指标是5个合格观察日的算术均值。本例手算为`0.0185 - 0.0025 = 0.016`。这是低组减高组的收益差，不是可执行多空账户收益，不含成交、费用、资金或卖空约束。

| 输入字段 | 含义 |
| --- | --- |
| `fld_metric_session` | 明确列出的合成交易日 |
| `fld_metric_code` | `SYN.000`至`SYN.019`的合成证券代码 |
| `fld_metric_turnover` | 换手率小数，0.01表示1% |
| `fld_metric_close` | 正数合成收盘价，用于独立未来标签 |

`inputs.py`生成180行输入。`source/operator.py`实现窗口、分组、标签及指标。`run.py`声明算子、指标和研究包并执行正式主链。项目逻辑不注册为框架内建算子。

## 输出与验证

输出目录保留`package/`、`bundle/`、`catalog/`、`inputs/`、`inputs.json`、`plan/`、`artifacts/`、`run/`、`results/`、`report.md`、`receipt.json`及准入和运行回执。正式Result保存120行分组观察与1行指标。最后20行观察的未来标签为空。回执提供结果ID、Result目录、Result存储根和报告路径。

```powershell
python -m pytest tests/test_turnover_factor_example.py -q --basetemp <新的测试目录> -p no:cacheprovider
```

测试核对手算窗口、5 组成员和 0.016 收益差。测试改变未来换手率和价格，核对过去分组不变。测试还运行正式主链并读取 Result 与报告。临时输入、事件、检查点和报告仅写入调用方指定目录。保留Result恢复所依赖的输入和工件。

## 接入真实数据

替换来源时需用自己的Catalog与已准入数据声明，不能把合成Catalog直接视为供应商数据证明。换手率统一为小数。分母必须明确采用流通股本或自由流通股本。历史股本和证券资格必须按当时可见日期对齐。ST、停牌、行业和成分也使用历史可见状态。

交易日窗口使用真实日历。缺行、停牌与缺失值政策须明确。禁止把下一个有价格的交易日自动当作次日。

标签需单独处理复权与公司行动，不能把未来收益或未来有效样本倒灌进分组。若要评价交易收益，应另建LEAN执行研究，声明费用、成交时点、资金和卖空约束。
